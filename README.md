# Google Trends UA Dashboard

This simple Looker Studio dashboard visualizes the most popular Google search queries in Ukraine.  
The report was created using **Google Looker Studio** and public data from **Google Trends**.

The dashboard allows users to explore top search queries, filter by region, and see popularity trends.

### 🧰 Tools used
- Google Looker Studio  
- Google Sheets (for data organization)  
- Public Google Trends data  

### 📊 Main insights
- Football matches and current events dominate top search trends.  
- The dashboard updates dynamically based on Google Trends data.
